天下壹家游戏隐私政策（通用）

生效日期：2026 年 11 月 25 日

更新日期：2026 年 11 月 25 日

适用范围：天下壹家开发、发布及运营的各款游戏（以下统称"本游戏"），包括但不限于《Factory 1986》（废土工厂）、《影代：血脉遗产》（Shadow Legacy）、《废土商队》（Wasteland Caravan）等。

开发者：天下壹家

一、引言

本隐私政策适用于天下壹家开发、发布及运营的各款游戏产品（以下统称"本游戏"）。我们非常重视您的隐私保护。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息，以及您享有的相关权利。各游戏的具体玩法、类型可能不同，但在个人信息处理上均遵循本政策所述原则。

核心承诺：本游戏为单机 / 离线游戏，不会收集、上传或共享您的任何个人信息。所有游戏数据仅保存在您的设备本地。

二、我们不收集的信息

本游戏不会收集以下任何信息：

  • 个人身份信息（姓名、身份证号、手机号、邮箱等）
  • 设备信息（设备型号、操作系统版本、设备 ID 等）
  • 位置信息（GPS 定位、IP 地址等）
  • 游戏行为数据（游戏时长、关卡进度、操作记录等）
  • 通讯录、相册、麦克风、摄像头等权限相关数据
  • 任何其他形式的个人信息

三、本地存储的数据

为了提供正常的游戏体验，本游戏会在您的设备本地存储以下数据（具体项目因游戏而异）：

  • 游戏进度：关卡 / 层数进度、角色或商队状态、资源与经济数据等
  • 历史记录：游戏记录、成就 / 图鉴解锁状态等
  • 游戏设置：语言偏好、音量设置、按键绑定等

重要说明：以上数据仅存储在您的设备本地，不会上传至任何服务器。清除应用数据或卸载游戏将导致这些数据永久丢失。

四、权限说明

本游戏不需要以下任何权限：

  • 网络访问权限（无需联网即可完整游玩）
  • 存储空间敏感权限（游戏数据自动保存在应用私有目录）
  • 麦克风/摄像头权限
  • 位置信息权限
  • 通讯录/短信权限
  • 任何其他敏感权限

五、第三方服务

本游戏不集成任何第三方 SDK 或服务，包括但不限于：

  • 广告 SDK
  • 数据分析 SDK
  • 社交分享 SDK
  • 支付 SDK
  • 推送通知 SDK

六、未成年人保护

本游戏适龄分级为 12 周岁及以上（具体以各游戏在应用商店标注的适龄提示为准）。由于本游戏不收集任何个人信息，也不需要联网，因此不存在未成年人个人信息保护问题。

建议家长关注未成年人的游戏时间，合理安排娱乐活动。

七、用户权利

由于本游戏不收集任何个人信息，您无需行使查阅、更正、删除等权利。您可以随时：

  • 清除游戏数据：在设备设置中清除应用数据或卸载游戏
  • 重置游戏设置：在游戏设置中恢复默认设置

八、隐私政策的变更

如本游戏未来更新导致隐私政策发生变化，我们将在游戏内或应用商店更新本政策，并修改生效日期。

建议您定期查看本政策以了解最新内容。
